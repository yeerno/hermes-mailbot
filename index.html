HermsAgent

A private, read-only Gmail assistant.

HermsAgent is a personal automation tool operated by a single user for their own mailbox. It connects to the user's Gmail account through the Google API using OAuth 2.0 and a single permission: https://www.googleapis.com/auth/gmail.readonly.

What it does

  • Reads the user's own email messages.
  • Searches the mailbox with Gmail search operators (sender, date, labels, attachments).
  • Summarises selected messages and threads for the account owner.

What it cannot do

  • It cannot send, reply to, forward, delete, archive, label or otherwise modify any message. The granted scope is read-only and Google enforces this at the API level — write calls are rejected with 403 insufficientPermissions.
  • It cannot access Calendar, Drive, Contacts, Sheets or Docs. Those permissions are never requested.

Who can use it

Only the owner of the account that authorised it. There is no sign-up, no multi-user service, and the app is not distributed.

Data handling

Message content is retrieved on demand, used to answer the owner's own queries, and is not sold, shared, or used for advertising. Full details are in the Privacy Policy.
